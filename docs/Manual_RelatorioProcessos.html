Módulo VBA — Relatório de Processos

Este documento explica como importar e utilizar o módulo RelatorioProcessos no Excel. O módulo cruza uma lista de processos recebida via chamado no VOIZA contra dois relatórios exportados do SAP — RESGATES e MOVIMENTO — identificando onde cada processo foi localizado e apontando eventuais divergências de data.

1. Visão Geral

O módulo recebe um relatório de processos e verifica, para cada linha, se o processo consta nos relatórios SAP de RESGATES ou MOVIMENTO. A busca ocorre em dois estágios: primeiro pelo número do processo no campo Texto do SAP; depois pelo valor financeiro, comparando com o Valor Recuperado e o Crédito Único do processo.

Ao final, três colunas são adicionadas automaticamente à aba PROCESSOS:

  • Localizado em — indica se o processo foi encontrado em Resgate, Movimento ou não foi localizado.
  • Correspondência — indica o critério usado: Número do processo, Valor recuperado ou Crédito único.
  • Retorno — informa se está Localizado, se há divergência de data em dias, ou se não foi localizado.

2. Estrutura do Arquivo Excel

O arquivo deve conter três abas com os nomes exatos indicados abaixo (incluindo maiúsculas e minúsculas).

2.1 Aba PROCESSOS — Lista de processos recebida via VOIZA

Esta aba é recebida pronta através do chamado aberto no VOIZA. A linha 1 deve ser o cabeçalho e os dados devem começar na linha 2. As colunas F, G e H são geradas automaticamente pela macro — não as preencha manualmente.

3. Lógica de Busca

Para cada linha da aba PROCESSOS, a macro executa dois estágios em sequência, encerrando assim que uma correspondência é encontrada.

3.1 Estágio 1 — Busca no RESGATES

Passo 1a — Por número do processo: se a coluna A (Processo Localizado) não estiver em branco, a macro percorre o campo Texto (coluna K) de todas as linhas do RESGATES procurando o número do processo. A comparação é insensível a maiúsculas/minúsculas e aceita o número em qualquer posição do texto. Se encontrado, o Retorno indica Localizado — com divergência de dias caso as datas sejam diferentes.

Passo 1b — Por valor: se não localizado no passo anterior, a macro compara o Valor em moeda da empresa (coluna H do RESGATES) com o Valor Recuperado e, na sequência, com o Crédito Único. O Valor Recuperado tem prioridade. Se encontrado, registra a correspondência e calcula a divergência de data.

3.2 Estágio 2 — Busca no MOVIMENTO

Executado somente para processos não localizados no Estágio 1. A macro compara o valor financeiro do MOVIMENTO com Valor Recuperado e Crédito Único (mesma prioridade do Passo 1b). Quando localizado, o Retorno indica Localizado — sem número de processo vinculado, acrescido da divergência de dias se houver.

3.3 Divergência de dias

Calculada em todos os casos de localização como a diferença absoluta em dias entre a Data do Crédito (coluna B do PROCESSOS) e a Data de documento (coluna D do SAP). Se a Data do Crédito estiver em branco ou inválida, a divergência não é calculada e o Retorno omite essa informação.

4. Como Importar o Módulo VBA

Siga os passos abaixo para adicionar o módulo ao seu arquivo Excel. Este procedimento é feito uma única vez por arquivo.

  1. Abra o arquivo Excel que contém as abas PROCESSOS, RESGATES e MOVIMENTO.
  2. Pressione Alt + F11 para abrir o Editor Visual Basic (VBE).
  3. No menu superior do VBE, clique em Arquivo → Importar Arquivo…
  4. Localize e selecione o arquivo RelatorioProcessos.bas e clique em Abrir.
  5. Confirme que o módulo RelatorioProcessos aparece na lista à esquerda (Módulos).
  6. Feche o VBE (Alt + Q ou clique no X da janela).
  7. Salve o arquivo Excel no formato .xlsm (Excel com Macros Habilitadas).
Ao abrir o arquivo futuramente, o Excel pode exibir uma barra amarela pedindo para "Habilitar Conteúdo". Clique nesse botão para que as macros funcionem.

5. Macros Disponíveis

5.1 ImportarRelatorios — importação e análise automática

Esta é a macro principal do fluxo de trabalho. Ao ser executada, abre dois diálogos em sequência para que você selecione os arquivos exportados do SAP, importa os dados para as abas RESGATES e MOVIMENTO e, em seguida, executa a análise automaticamente.

  1. Certifique-se de que as abas se chamam exatamente PROCESSOS, RESGATES e MOVIMENTO.
  2. Cole os dados recebidos do VOIZA na aba PROCESSOS (a partir da linha 2, com cabeçalho na linha 1).
  3. Pressione Alt + F8 para abrir a janela de macros.
  4. Selecione ImportarRelatorios na lista e clique em Executar.
  5. Na primeira janela, selecione o arquivo de RESGATES exportado do SAP e clique em Abrir.
  6. Na segunda janela, selecione o arquivo de MOVIMENTO exportado do SAP e clique em Abrir.
  7. Aguarde. Os dados serão importados e a análise será executada automaticamente.
  8. Ao final, uma mensagem exibirá o resumo: linhas analisadas, localizadas em Resgate, localizadas em Movimento e não localizadas.
A macro ImportarRelatorios substitui os dados anteriores das abas RESGATES e MOVIMENTO antes de importar. Não é necessário limpar os dados manualmente antes de utilizá-la.

5.2 AnalisarProcessos — reprocessar sem reimportar

Executa a análise diretamente sobre os dados já presentes nas abas RESGATES e MOVIMENTO, sem abrir nenhum diálogo de arquivo. Use quando os relatórios SAP já estiverem importados e você quiser rodar a análise novamente — por exemplo, após corrigir dados na aba PROCESSOS.

  1. Pressione Alt + F8 para abrir a janela de macros.
  2. Selecione AnalisarProcessos e clique em Executar.
  3. As colunas F, G e H da aba PROCESSOS serão atualizadas com os resultados.

5.3 LimparAnalise — limpar resultados

Apaga o conteúdo das colunas F, G e H (Localizado em, Correspondência e Retorno) da aba PROCESSOS, incluindo os cabeçalhos. Use para limpar os resultados antes de um reprocessamento manual.

  1. Pressione Alt + F8 para abrir a janela de macros.
  2. Selecione LimparAnalise e clique em Executar.
  3. As colunas F, G e H serão apagadas. Execute AnalisarProcessos para reprocessar.

6. Exportando os Relatórios do SAP

Os relatórios de RESGATES e MOVIMENTO são gerados na transação FBL3H, utilizando o layout /AGING. São necessárias duas exportações separadas: uma para cada relatório, variando apenas a conta ou o filtro aplicado.

6.1 Passo a passo para exportação

  1. Acesse a transação FBL3H no SAP.
  2. Configure os filtros desejados (conta específica para RESGATES; relatório geral para MOVIMENTO).
  3. Aplique o layout /AGING: clique no ícone de layout (ou menu Configurações → Layouts → Carregar) e selecione /AGING.
  4. Execute o relatório (F8).
  5. Clique com o botão direito sobre o relatório e selecione Exportar como → Planilha eletrônica → Formato Microsoft Excel (*.xlsx).
  6. Salve o arquivo em um local de fácil acesso.
  7. Repita os passos para o segundo relatório.
Utilize sempre o layout /AGING. Outros layouts podem gerar colunas em ordem diferente, fazendo com que a macro leia campos incorretos e produza resultados errados.

8. Fluxo Resumido de Uso

Siga este fluxo sempre que receber um novo chamado no VOIZA:

  1. Abra o chamado no VOIZA e copie os dados de processos para a aba PROCESSOS (linha 1 = cabeçalho, dados a partir da linha 2).
  2. Exporte os dois relatórios da transação FBL3H do SAP usando o layout /AGING: um para RESGATES e um para MOVIMENTO.
  3. No Excel, execute ImportarRelatorios e selecione os dois arquivos exportados quando solicitado.
  4. Os dados serão importados e a análise ocorrerá automaticamente.
  5. Revise as linhas com Retorno = "Não localizado" na coluna H e verifique se os arquivos SAP importados estão corretos.
  6. Se necessário, corrija os dados e execute AnalisarProcessos para reprocessar sem reimportar.
