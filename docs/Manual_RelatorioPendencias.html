Manual de Uso

Módulo VBA — Relatório de Pendências SAP

Este documento explica como importar e utilizar o módulo RelatorioPendencias no Excel, e como preencher corretamente a tabela de regras (aba BASE) para identificação automática das áreas responsáveis por partidas em aberto exportadas do SAP (transação FBL3H).

1. Visão Geral

O módulo processa um relatório de partidas em aberto do SAP e, para cada linha, identifica a Área Responsável pela contabilização com base em regras definidas pelo usuário. Ao final, três colunas são adicionadas automaticamente ao relatório:

  • Data Base — data em que o processamento foi executado.
  • Dias em Aberto — diferença em dias entre a Data Base e a Data de Lançamento.
  • Área Responsável — área identificada pelas regras da tabela BASE.
Linhas com o campo Tipo de Documento em branco são excluídas automaticamente antes do processamento.

2.2 Aba BASE — Tabela de regras

Esta aba contém as regras usadas para identificar a área responsável. A linha 1 deve ser o cabeçalho e as regras começam na linha 2.

ColunaCampoDescrição

Qualquer combinação de colunas é válida — inclusive regras com apenas Regex e Área Responsável preenchidos (colunas A, B e C em branco). Nesse caso a conta é tratada como coringa e o texto é avaliado somente pelo padrão Regex.

3. Como Preencher a Tabela BASE

3.1 Lógica de pontuação (score)

Para cada linha do SAP, a macro percorre todas as regras da BASE e calcula uma pontuação de 0 a 4. A regra com maior pontuação vence. Em caso de empate, prevalece a primeira regra na ordem da tabela.

Condição avaliadaPontos
Conta do Razão em branco na BASE  ou  bate com a do SAP +1
Campo "Começa em" não está vazio  e  o Texto do SAP começa com ele +1
Campo "Contém" não está vazio  e  o Texto do SAP contém ele +1
Campo "Regex" não está vazio  e  o Texto do SAP corresponde ao padrão +1
Eliminação: se um campo não estiver em branco e não bater com o SAP, a pontuação da regra vai a zero e ela é descartada imediatamente.

3.3 Casos especiais

  • Conta em branco na BASE — a regra se aplica a qualquer conta do SAP (útil para textos que aparecem em múltiplas contas).
  • Apenas Regex + Área preenchidos — colunas A, B e C podem ficar em branco. A regra será aplicada a qualquer conta cuja linha do SAP corresponda ao padrão Regex.
  • "Começa em" e "Contém" ambos em branco — a regra é identificada apenas pela conta. Todos os textos daquela conta serão atribuídos à área.
  • Nenhuma regra bate — a célula de Área Responsável recebe "Não identificado". Adicione uma regra na BASE para cobrir esse caso.
Todas as comparações de texto são insensíveis a maiúsculas/minúsculas. "pix", "PIX" e "Pix" são tratados da mesma forma.

3.4 Como usar o campo Regex

Use a coluna Regex (D) quando o texto do SAP não tem uma parte fixa que permita usar "Começa em" ou "Contém" — como números de processo, códigos e identificadores com estrutura variável.

O Regex é uma expressão regular: uma sequência de caracteres que descreve um padrão de texto. A macro testa se o Texto do SAP corresponde ao padrão informado. A comparação é insensível a maiúsculas/minúsculas.

Referência rápida dos símbolos mais usados:

SímboloSignificadoExemplo
\dQualquer dígito (0–9)\d corresponde a 3, 7
{n}Exatamente n repetições\d{4} corresponde a 2020
\.Ponto literal\. corresponde a . (não a qualquer caractere)
-Hífen literal- corresponde a -
(espaço)Espaço literal\d{4} \d{7} corresponde a XXXX XXXXXXX
^Início do texto^\d{4} — texto deve começar com 4 dígitos
$Fim do texto\d{4}$ — texto deve terminar com 4 dígitos

Exemplos de padrões:

Texto SAPPadrão RegexCorrespondência
1234567-89.0123.4.56.7890 ^\d{7}-\d{2}\.\d{4}\.\d{1}\.\d{2}\.\d{4}$ Número de processo judicial
1234 5678901 ^\d{4} \d{7}$ Código com 4 dígitos, espaço e 7 dígitos
1234567-89.0123 ^\d{7}-\d{2}\.\d{4}$ Identificador com hífen e ponto
Use ^ e $ para garantir que o padrão corresponda ao texto inteiro — sem eles, um trecho qualquer do texto já satisfaz a regra, o que pode gerar falsos positivos. Deixe o campo Regex em branco quando "Começa em" ou "Contém" já forem suficientes.

3.5 Boas práticas

  • Coloque as regras mais específicas primeiro na tabela BASE.
  • Use "Começa em" quando o texto sempre inicia com um padrão fixo (ex: TED-TRANSF).
  • Use "Contém" quando o padrão pode aparecer em qualquer posição do texto.
  • Use "Regex" apenas quando o texto não tem parte fixa — somente estrutura variável.
  • Deixe a Conta do Razão em branco apenas quando o texto for único o suficiente para não gerar conflitos com outras contas.
  • Revise as linhas marcadas como "Não identificado" e adicione as regras faltantes.

4. Como Importar o Módulo VBA

Siga os passos abaixo para adicionar o módulo ao seu arquivo Excel. Este procedimento é feito uma única vez por arquivo.

  1. Abra o arquivo Excel que contém as abas SAP e BASE.
  2. Pressione Alt + F11 para abrir o Editor Visual Basic (VBE).
  3. No menu superior do VBE, clique em Arquivo → Importar Arquivo…
  4. Localize e selecione o arquivo RelatorioPendencias.bas e clique em Abrir.
  5. Confirme que o módulo RelatorioPendencias aparece na lista à esquerda (Módulos).
  6. Feche o VBE (Alt + Q ou clique no X da janela).
  7. Salve o arquivo Excel no formato .xlsm (Excel com Macros Habilitadas).
Ao abrir o arquivo futuramente, o Excel pode exibir uma barra amarela pedindo para "Habilitar Conteúdo". Clique nesse botão para que as macros funcionem.

5. Macros Disponíveis

5.1 ImportarSAP — importação e processamento automático

Esta é a macro principal do fluxo de trabalho. Ao ser executada, abre um diálogo para que você selecione o arquivo exportado do SAP, importa os dados diretamente para a aba SAP e, em seguida, executa o processamento automaticamente.

  1. Certifique-se de que as abas se chamam exatamente SAP e BASE.
  2. Pressione Alt + F8 para abrir a janela de macros.
  3. Selecione ImportarSAP na lista e clique em Executar.
  4. Na janela que abrir, localize e selecione o arquivo exportado do SAP (.xlsx, .xlsm ou .xls).
  5. Aguarde. Os dados serão importados e o processamento será executado automaticamente.
  6. Ao final, uma mensagem exibirá o resumo: linhas analisadas, atribuídas e não identificadas.
A macro ImportarSAP substitui os dados anteriores da aba SAP antes de importar. Não é necessário limpar os dados manualmente antes de utilizá-la.

5.2 LimparResultados — limpar e reprocessar

Apaga o conteúdo das colunas L, M e N (Data Base, Dias em Aberto e Área Responsável) e, na sequência, executa ProcessarPendencias automaticamente. Use quando quiser forçar um reprocessamento completo a partir dos dados atuais da aba SAP.

  1. Pressione Alt + F8 para abrir a janela de macros.
  2. Selecione LimparResultados e clique em Executar.
  3. As colunas L, M e N serão limpas e o processamento será iniciado automaticamente.
Após a limpeza, o processamento roda imediatamente sem necessidade de executar outra macro.

6. Exportando o Relatório do SAP

O relatório deve ser gerado na transação FBL3H utilizando obrigatoriamente a variante AGING, que já possui pré-configurados as empresas, as contas do razão e o layout com as colunas esperadas pelo módulo.

6.1 Passo a passo para exportação

  1. Acesse a transação FBL3H no SAP.
  2. Clique em Chamar variante… (Shift + F5).
  3. No campo de variante, informe AGING e confirme.
  4. Execute o relatório (F8).
  5. Clique com o botão direito sobre o relatório para abrir o menu suspenso e selecione Exportar como → Planilha eletrônica → Formato Microsoft Excel (*.xlsx).
  6. Salve o arquivo em um local de fácil acesso.
  7. No Excel, execute a macro ImportarSAP e selecione o arquivo salvo.
Utilize sempre a variante AGING. Outras variantes ou layouts podem gerar colunas em ordem diferente, fazendo com que a macro leia campos incorretos e produza resultados errados.

O arquivo selecionado não contém dados a partir da linha 2 O arquivo SAP selecionado está vazio ou só tem o cabeçalho. Verifique se o arquivo exportado do SAP está correto.
Nenhum dado encontrado na aba 'SAP' A aba SAP está vazia ou só tem o cabeçalho. Execute ImportarSAP para importar o relatório.
BASE vazia A aba BASE não tem nenhuma regra com Área Responsável preenchida. Adicione pelo menos uma regra a partir da linha 2, com a coluna E (Área Responsável) preenchida.

⚠ Não identificado na coluna N Nenhuma regra da BASE corresponde àquela linha. Adicione uma regra na BASE cobrindo o texto e/ou conta daquela linha.

8. Fluxo Resumido de Uso

Siga este fluxo sempre que receber um novo relatório do SAP:

  1. Exporte o relatório FBL3H do SAP usando a variante AGING.
  2. No Excel, execute ImportarSAP e selecione o arquivo exportado.
  3. Os dados serão importados e o processamento ocorrerá automaticamente.
  4. Revise as linhas marcadas como "Não identificado" na coluna N.
  5. Se necessário, atualize as regras na aba BASE e execute LimparResultados — ele limpa e reprocessa automaticamente.
  6. Repita o passo 5 até que todas as linhas estejam identificadas.
