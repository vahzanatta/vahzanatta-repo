Manual de Uso

Módulo VBA — Relatório de Pendências SAP

Este documento explica como importar e utilizar o módulo ModuloPendencias no Excel, e como preencher corretamente a tabela de regras (aba BASE) para identificação automática das áreas responsáveis por partidas em aberto exportadas do SAP (transação FBL3H).

1. Visão Geral

O módulo processa um relatório de partidas em aberto do SAP e, para cada linha, identifica a Área Responsável pela contabilização com base em regras definidas pelo usuário. Ao final, três colunas são adicionadas automaticamente ao relatório:

  • Data Base — data em que o processamento foi executado.
  • Dias em Aberto — diferença em dias entre a Data Base e a Data de Lançamento.
  • Área Responsável — área identificada pelas regras da tabela BASE.
Linhas com o campo Tipo de Documento em branco são excluídas automaticamente antes do processamento.

2. Exportando o Relatório do SAP

O relatório deve ser gerado na transação FBL3H utilizando obrigatoriamente a variante AGING, que já possui pré-configurados as empresas, as contas do razão e o layout com as colunas esperadas pelo módulo.

2.1 Passo a passo para exportação

  1. Acesse a transação FBL3H no SAP.
  2. Clique em Chamar variante… (Shift + F5).
  3. No campo de variante, informe AGING e confirme.
  4. Execute o relatório (F8).
  5. Exporte para Excel: menu Lista → Exportar como → Planilha eletrônica → Formato Microsoft Excel (*.xlsx).
  6. Salve o arquivo e cole os dados na aba SAP do arquivo Excel com o módulo, a partir da linha 2.
⚠ Utilize sempre a variante AGING. Outras variantes ou layouts podem gerar colunas em ordem diferente, fazendo com que a macro leia campos incorretos e produza resultados errados.

4. Como Preencher a Tabela BASE

4.1 Lógica de pontuação (score)

Para cada linha do SAP, a macro percorre todas as regras da BASE e calcula uma pontuação de 0 a 3. A regra com maior pontuação vence. Em caso de empate, prevalece a primeira regra na ordem da tabela.

Condição avaliadaPontos
Conta do Razão em branco na BASE  ou  bate com a do SAP +1
Campo "Começa em" não está vazio  e  o Texto do SAP começa com ele +1
Campo "Contém" não está vazio  e  o Texto do SAP contém ele +1
Eliminação: se um campo não estiver em branco e não bater com o SAP, a pontuação da regra vai a zero e ela é descartada imediatamente.

4.3 Casos especiais

  • Conta em branco na BASE — a regra se aplica a qualquer conta do SAP (útil para textos que aparecem em múltiplas contas).
  • "Começa em" e "Contém" ambos em branco — a regra é identificada apenas pela conta. Todos os textos daquela conta serão atribuídos à área.
  • Nenhuma regra bate — a célula de Área Responsável recebe "⚠ Não identificado". Adicione uma regra na BASE para cobrir esse caso.
Todas as comparações de texto são insensíveis a maiúsculas/minúsculas. "pix", "PIX" e "Pix" são tratados da mesma forma.

4.4 Boas práticas

  • Coloque as regras mais específicas primeiro na tabela BASE.
  • Use "Começa em" quando o texto sempre inicia com um padrão fixo (ex: PIX TRANSF).
  • Use "Contém" quando o padrão pode aparecer em qualquer posição do texto.
  • Deixe a Conta do Razão em branco apenas quando o texto for único o suficiente para não gerar conflitos com outras contas.
  • Revise as linhas marcadas como "⚠ Não identificado" e adicione as regras faltantes.

5. Como Importar o Módulo VBA

Siga os passos abaixo para adicionar o módulo ao seu arquivo Excel. Este procedimento é feito uma única vez por arquivo.

  1. Abra o arquivo Excel que contém as abas SAP e BASE.
  2. Pressione Alt + F11 para abrir o Editor Visual Basic (VBE).
  3. No menu superior do VBE, clique em Arquivo → Importar Arquivo…
  4. Localize e selecione o arquivo ModuloPendencias.bas e clique em Abrir.
  5. Confirme que o módulo ModuloPendencias aparece na lista à esquerda (Módulos).
  6. Feche o VBE (Alt + Q ou clique no X da janela).
  7. Salve o arquivo Excel no formato .xlsm (Excel com Macros Habilitadas).
⚠ Ao abrir o arquivo futuramente, o Excel pode exibir uma barra amarela pedindo para "Habilitar Conteúdo". Clique nesse botão para que as macros funcionem.

6. Executando as Macros

6.1 ProcessarPendencias — macro principal

Esta macro realiza todo o processamento: exclui linhas inválidas, identifica as áreas responsáveis e preenche as colunas K, L e M.

  1. Certifique-se de que as abas se chamam exatamente SAP e BASE.
  2. Pressione Alt + F8 para abrir a janela de macros.
  3. Selecione ProcessarPendencias na lista e clique em Executar.
  4. Aguarde. Para arquivos grandes (100 mil+ linhas) o processamento pode levar alguns minutos.
  5. Ao final, uma mensagem exibirá o resumo: linhas analisadas, atribuídas e não identificadas.

6.2 LimparResultados — macro auxiliar

Apaga o conteúdo das colunas K, L e M (incluindo os cabeçalhos) para permitir reprocessamento com novos dados ou regras.

  1. Pressione Alt + F8 para abrir a janela de macros.
  2. Selecione LimparResultados e clique em Executar.
  3. Confirme que as colunas K, L e M foram esvaziadas.
Execute LimparResultados antes de ProcessarPendencias sempre que substituir os dados do SAP ou atualizar as regras da BASE.

7. Mensagens e Situações Comuns

Mensagem / SituaçãoCausaSolução
Aba 'SAP' não encontrada A aba com os dados não existe ou tem nome diferente. Renomeie a aba para SAP (exatamente, com maiúsculas).
Aba 'BASE' não encontrada A tabela de regras não existe ou tem nome diferente. Renomeie a aba para BASE (exatamente, com maiúsculas).
Nenhum dado encontrado na aba 'SAP' A aba SAP está vazia ou só tem o cabeçalho. Cole os dados do FBL3H a partir da linha 2.
BASE vazia A aba BASE não tem nenhuma regra cadastrada. Adicione pelo menos uma regra a partir da linha 2.
Todas as linhas foram excluídas Todas as linhas do SAP tinham Tipo de Documento em branco. Verifique se o relatório foi exportado corretamente do SAP.
⚠ Não identificado na coluna M Nenhuma regra da BASE corresponde àquela linha. Adicione uma regra na BASE cobrindo o texto e/ou conta daquela linha.

8. Fluxo Resumido de Uso

Siga este fluxo sempre que receber um novo relatório do SAP:

  1. Exporte o relatório FBL3H do SAP.
  2. Cole os dados na aba SAP a partir da linha 2 (preservando o cabeçalho na linha 1).
  3. Verifique e atualize as regras na aba BASE se necessário.
  4. Execute LimparResultados para apagar resultados anteriores.
  5. Execute ProcessarPendencias para processar o novo relatório.
  6. Revise as linhas marcadas como "⚠ Não identificado" e adicione regras se necessário.
  7. Repita os passos 4–6 até que todas as linhas estejam identificadas.
